# Post-E870 first-place research and fallback plan

Date: 2026-07-30 (Asia/Kolkata)

## Executive decision

Do not spend a competition validation or manual submission on another
currently available feature. E850, E860, and E870 each failed before consuming
competition outcomes, but they also closed the last three genuinely new local
mechanisms found in the source/log audit: speaker attribution repair, spoken
math normalization, and misconception-atlas retrieval.

APTA is the strongest remaining prospective modeling source, but it is not a
guaranteed rescue and it is not being treated as one. The correct portfolio is:

1. keep the protected v0.5 submission ready;
2. use the pending APTA source only if its real learner/outcome linkage passes
   the already frozen landing gate;
3. maintain a narrow outcome-linked source reserve rather than relabeling
   rejected families;
4. stop outcome search if those sources cannot establish a new independent
   construct;
5. invest in the competition report while the rank remains in the observed top
   15.

The last observed board has first place at `0.6008`, fifth at `0.6040`, tenth
at `0.6053`, and v0.5 at `0.6054` near eleventh. Reaching the first-place
safety target `0.6005` would require about `0.0049` public log-loss gain.
Nothing currently validated supports that projection. A manual submission is
useful only after a locally verified candidate exists; resubmitting v0.5 or a
known regression cannot improve the model.

## What the completed evidence says

### Durable positives

- Full-session sparse text remains the strongest general process signal.
- Role-separated text helps.
- Raw packaged BGE-base is the strongest stable semantic component. Replacing
  BGE-small with BGE-base produced the only later robust component gain and the
  public v0.5 improvement.
- Ordered feedback adjacency adds a small, stable process signal.

### Repeated failure pattern

Recent independent heads repeatedly improve only a narrow aspect of the task
and then regress probability quality:

- E770 tutor-move/state interactions: mean loss gain `-0.001927`;
- E810 productive numeric elaboration: `-0.002049`;
- E820 contrastive objective alignment: `-0.001789`;
- E830 curriculum progression: `-0.001670`;
- E840 StudyChat longitudinal behavior: failed its external outcome gate;
- E850 speaker denoising: failed external/target-free macro-F1 and coverage;
- E860 ASR normalization: reduced real transcript/objective alignment;
- E870 misconception atlas: all-label top-5 `0.527273`, below `0.65`, with
  bootstrap lower bound `0.427273`.

E770/E810/E820/E830 all particularly regressed `V_seen` and `V_style`, even
when `V_objective` was close to neutral or slightly better. This is evidence
against another objective prior, semantic adaptation, published count, or
hand-authored process head. It is not permission to search smaller blend
weights or recalibrate rejected scores.

## Branch A: APTA, if access is granted

### A0. Source gate only

Run `APTA_target_free_source_audit_v1` before extracting a modeling target.
Require all of the following:

- safe, hash-manifested source files;
- supported clean transaction and auxiliary tables;
- stable learner and session/class groups;
- solver/tutor role;
- experimental condition;
- ordered problem/step/transaction structure and transaction correctness;
- a real pre/post/gain/assessment outcome distinct from step correctness;
- at least 50 learners linked between transactions and the learning outcome.

Any failure stops APTA as a modeling source. It does not authorize imputation,
paper-table reconstruction, relaxed linkage, or use of step correctness as a
learning gain.

### A1. External benchmark freeze

Only after A0 passes, preregister one reciprocal-role trajectory question:

> Does ordered solver/tutor role switching plus skill-state change predict
> held-out learner gain beyond static pretest, opportunity, correctness, and
> activity-count baselines?

The exact data will decide whether this question is identifiable. Freeze
learner-grouped folds, target, baseline, feature sequence, estimator, seed,
proper scores, group bootstrap, and minimum effect before any outcome score.
The candidate must beat a strong static baseline across study sites and
conditions; pooled significance is insufficient.

No content-only chat model, generic tutor move model, correctness transfer, or
bag-of-actions model is allowed because those mechanisms are closed.

### A2. Target-free competition transfer

If and only if A1 passes:

- map only deployable role/trajectory features into competition transcripts;
- prove finite/nonconstant features, session invariance, coverage in every
  style cell, and comparable external/competition distributions;
- benchmark runtime and package feasibility;
- bind the cache by hash before outcomes.

A2 can reject the source without consuming a competition validation.

### A3. Single selection validation

Only a full A0-A2 pass authorizes one frozen `V_seen`/`V_objective`/`V_style`
validation. Require the existing literal conditions:

- at least `0.0016` mean log-loss gain over raw v0.5;
- all three environments improve;
- worst fold regression at most `0.0005`;
- macro AUROC, Brier, and ECE non-regression;
- at least `0.95` positive-gain support in both session and semantic-family
  bootstraps.

A failed clause closes the exact APTA branch without feature, weight, target,
estimator, condition, role, or subgroup rescue.

## Branch B: if APTA is unusable or fails externally

Perform a source-only feasibility audit of the ITSPOKE/WOZ release only after
legitimate access exists. Before any request or download, verify current terms,
redistribution limits, exact learner count, transcript/pre/post linkage, and
whether prize-related use is permitted. Do not create a second DataShop
account or accept new terms silently.

ITSPOKE may continue only if a repository/log audit proves a construct
independent of:

- E510 timing;
- E580-E630 correctness/knowledge-state transfer;
- E710 coherence;
- E780 uncertainty/challenge;
- E840 confusion/help-seeking behavior;
- E850 speaker repair; and
- E860 ASR normalization.

The likely affect/uncertainty formulation overlaps several of these and is
therefore not currently preregistered. Small learner count and physics-domain
shift also make a robust `0.0016` competition path doubtful. It is a reserve,
not a reason to spend outcomes.

If no independent construct survives that audit, stop this branch before
training. BEETLE II remains only a source lead unless a lawful package with
both dialogue and learner outcomes is found.

## Branch C: if no outcome-linked source survives

Do not manufacture E880. Preserve v0.5, the sealed `V_final`, and the two
manual slots. Shift compute and analysis to report-quality evidence:

1. consolidate the robustness matrix for v0.5 and every closed branch;
2. produce calibration, environment, and bootstrap figures from already
   authorized artifacts;
3. document why external retrieval success did not transfer to learning
   outcomes;
4. build the reproducibility/lineage table with source revisions, licenses,
   seeds, runtimes, and hashes;
5. explain the stable finding: content semantics plus ordered feedback transfer
   better than generic pedagogical labels across typed and ASR providers;
6. keep the protected v0.5 ZIP locally verified and submission-ready.

The competition weights relevance and generalizability heavily; a rigorous
top-15 report remains valuable even if no honest model clears v0.5. It is also
more productive than using the public board as a hidden validation fold.
